# 🎮 포켓 룰렛

**공대인의 밤** 부스용 체험형 슬롯머신입니다.
릴 3개를 방문객이 직접 하나씩 멈춰서, **같은 포켓몬이 2칸 이상** 나오면 미션 성공 → 스탬프 지급!

- 옛날 휴대용 게임기 느낌의 **도트 스타일** (갈무리 픽셀 폰트, 대화창 타이핑, 8비트 효과음)
- 인터넷 없이 **오프라인 동작** (외부 CDN 없음, 폰트·효과음 모두 내장)
- 태블릿·모니터 터치에 맞춘 큰 버튼, 키보드 조작 지원
- 🌟 2% 확률의 **전설의 포켓몬 등장 연출** + 스탬프 3개
- 새로고침하면 초기화 (저장 기능 없음)

> 저작권·초상권 때문에 PNG는 `.gitignore`로 저장소에 올리지 않습니다. 부스 PC에는 USB 등으로 따로 복사하세요.

## ▶️ 실행 방법

`index.html`을 더블클릭(file://)으로 열면 브라우저 보안 정책 때문에 이미지나 폰트가 안 뜰 수 있습니다.
**로컬 서버로 여는 것을 권장합니다.**

```bash
cd 포켓룰렛
python -m http.server 8000
```
→ 브라우저에서 **http://localhost:8000** 접속
(`python`이 없다고 나오면 `py -m http.server 8000`)

**부스 운영 팁**
- 브라우저 전체화면: **F11**
- 서버를 실행한 터미널 창은 행사가 끝날 때까지 **닫지 마세요**

## 🕹️ 조작법

| 동작 | 터치 / 마우스 | 키보드 |
|---|---|---|
| 회전 시작 | `▶ 시작` | `Space` / `Enter` |
| 릴 멈추기 | 각 릴 아래 `STOP` (1 → 2 → 3 순서) | `1` `2` `3` 또는 `Space` |
| 전설 연출 건너뛰기 | 화면 아무 곳이나 터치 | `Space` |
| 다시 하기 | 결과 화면의 `▶ 다시 하기` | `Space` / `Enter` |
| 소리 켜기/끄기 | 오른쪽 아래 🔊 | – |

- 시작 후 0.6초 동안은 STOP이 눌리지 않습니다 (연타 방지)
- 결과 화면의 `다시 하기`는 잠시 뒤 활성화됩니다 (방문객 오터치 방지)

## 🎲 확률 구조

시작 버튼을 누르는 **순간 결과가 먼저 확정**되고, 애니메이션은 그 결과를 향해 멈춥니다.
STOP 타이밍은 연출일 뿐, 결과를 바꾸지 않습니다.

1. **이스터에그 판정 먼저**: 2% 확률로 3칸 모두 `메가임형대` (LUCKY!)
2. 낙첨(98%)이면 3개 릴이 **서로 독립적으로** 일반 4종 중 **각 25%** 균등 추첨
3. `메가임형대`는 일반 추첨 풀에 없어서, **1~2칸만 나오는 경우는 구조적으로 불가능**

| 결과 | 계산 | 확률 | 스탬프 |
|---|---|---|---|
| 🌟 LUCKY (전설 등장) | 2% | **2.00%** | **3개** |
| ✅ 미션 성공 (2칸 이상 일치) | 98% × (1 − 4·3·2 / 4³) = 98% × 62.5% | **61.25%** | 1개 |
| ❌ 미션 실패 (전부 다름) | 98% × 37.5% | **36.75%** | – |

> 📌 10만 회 시뮬레이션 결과: LUCKY 1.99% / 성공 61.16% / 실패 36.85%, 메가임형대 낱개 등장 0회
> 방문객 100명 기준 스탬프 약 **67개** (일반 성공 약 61개 + LUCKY 약 2회 × 3개)

## ⚙️ 설정 바꾸기

`index.html`의 `⚙️ 설정값` 부분만 수정하면 됩니다.

```js
const EASTER_EGG_CHANCE = 0.02;   // 잭팟 확률 (0.05 = 5%)
const SUCCESS_MATCH     = 2;      // 몇 칸 일치부터 성공인지
const STOP_IN_ORDER     = true;   // false면 아무 릴이나 먼저 멈출 수 있음
const SPIN_SPEED        = 16;     // 회전 속도 (칸/초)
const LUCKY_STAMPS      = 3;      // 전설 등장 시 지급 스탬프 수
const TYPE_SPEED_MS     = 28;     // 대화창 글자 찍히는 속도 (ms)
```

## 🧪 리허설용 테스트 모드

주소 뒤에 `?force=`를 붙이면 결과를 강제로 정할 수 있습니다. 화면 왼쪽 위에 파란 **테스트 모드** 배지가 표시됩니다.

| 주소 | 결과 |
|---|---|
| `http://localhost:8000/?force=lucky` | 전설 등장 + LUCKY 연출 |
| `http://localhost:8000/?force=win` | 미션 성공 연출 |
| `http://localhost:8000/?force=lose` | 미션 실패 연출 |

> 실제 운영 때는 `?force=` 없이 **http://localhost:8000** 으로 여세요.

## 🛠️ 기술 포인트

| 기능 | 구현 |
|---|---|
| 결과 선결정 | 시작 시점에 `decideResult()`로 확정 → STOP 시 **6칸 앞 화면 밖 자리**에 결과를 끼워 넣고 그 위치로 감속 |
| 무한 릴 | DOM 칸 **4개만** 재활용하는 가상 스크롤 (`transform`으로 위치만 이동) |
| 자연스러운 정지 | ease-out-cubic 시작 속도(3·거리/시간)를 회전 속도와 맞춰 속도가 끊기지 않음 |
| 게임 흐름 | 상태 머신 `loading → ready → spinning → judging → result`로 중복 입력 차단 |
| 전설 연출 | 조우 → 실루엣 → 정체 공개 3단계, 타이머를 배열로 관리해 건너뛰기·리셋 시 일괄 취소 |
| 도트 스타일 | `text-shadow` 픽셀 외곽선, `clip-path` 계단 모서리, `steps()` 8비트 애니메이션 |
| 효과음 | Web Audio API로 사각파·톱니파 합성 (음원 파일 0개) |
| 컨페티 | Canvas + 중력 시뮬레이션, 좌표를 4px 격자로 반올림 |
| 예외 처리 | 이미지 누락 시 파일명 경고 + 이름 글자로 대체 표시, 앱은 계속 동작 |

## 🛠️ 문제 해결

| 증상 | 해결 |
|---|---|
| 상단에 `images/○○○.png 파일을 찾을 수 없습니다` | 파일명 오타·띄어쓰기·확장자(`.PNG` ↔ `.png`, `.jpg`) 확인 |
| 이미지·폰트가 전부 안 뜸 | 더블클릭 대신 **로컬 서버**로 열기 |
| 코드를 고쳤는데 그대로임 | 브라우저에서 **Ctrl + F5** (강력 새로고침) |
| 전설 실루엣이 네모로 보임 | `메가임형대.png`를 **배경 투명 PNG**로 교체 |
| 소리가 안 남 | 🔊 버튼 확인. 첫 터치 이후부터 소리 재생 (브라우저 정책) |
